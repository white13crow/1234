Lab3 Full Angular App

This project implements features described in the lab PDF:
- product list with alerts, details, cart, shipping via HttpClient
- auth (Admin / 12345) and profile guard
- routing: /, /login, /news, /profile, /products, /products/:id, /cart, /shipping

How to run:
1. Install Node.js (LTS recommended)
2. Run: npm install
3. Run: ng serve
4. Open http://localhost:4200

Notes:
- The project is prepared for Angular 14.x (package.json pinned).
- If ng serve fails, ensure @angular-devkit/build-angular is installed (devDependency included).
